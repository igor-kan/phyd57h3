Fork-join parallelism, race conditions, reduction clauses, and memory bandwidth limits on multicore CPUs.

1. The Fork-Join Parallel Execution Model

OpenMP uses the fork-join model of parallel execution: - The master thread executes sequential sections of code. - When an #pragma omp parallel (C/C++) or !$omp parallel (Fortran) construct is encountered, the master thread creates or forks a team of worker threads. - At the end of the parallel construct, an implicit barrier synchronizes the team and worker threads join back.

Parallel For-Loops

#pragma omp parallel for schedule(static) reduction(+:total_sum)
for (int i = 0; i < N; i++) {
    total_sum += compute_energy(i);
}
!$omp parallel do schedule(static) reduction(+:total_sum)
do i = 1, N
    total_sum = total_sum + compute_energy(i)
end do
!$omp end parallel do

2. Race Conditions & Synchronization

A race condition occurs when multiple threads concurrently access the same memory location, and at least one access is a write, without synchronization.

Remedial Constructs:

  • Critical Sections (#pragma omp critical): Enforces mutually exclusive execution of a code block. Beware: high contention drops throughput dramatically.
  • Atomic Directives (#pragma omp atomic): Leverages hardware atomic CPU instructions (e.g. LOCK XADD) for simple scalar updates with minimal overhead.
  • Reduction (reduction(op:var)): Generates private copies per thread, accumulating into private registers and combining results upon loop termination.

3. Computational vs. Bandwidth Limitations

For simple array sweeps (like the 5-point Laplace stencil or SAXPY \(y = ax + y\)), modern CPUs can execute multiple floating point operations per cycle (SIMD AVX-512 / AVX2). However, performance is almost always throttled by the memory bus bandwidth (\(\sim 100-150\text{ GB/s}\) on dual-channel DDR4/DDR5).

\[\text{Arithmetic Intensity} = \frac{\text{FLOPs performed}}{\text{Bytes transferred from RAM}}\]

When arithmetic intensity is low, optimization level -O3 yields no additional speedup over -O2 because the memory bus is already saturated.
