1. Introduction: Number Theory in Computational Physics

While numerical physics is frequently identified with continuous differential equations (Navier-Stokes, Schrödinger, Einstein field equations), discrete algorithms and algebraic number theory play an indispensable role across modern computational physics: 1. Crystallography and Bravais Lattices: Identifying the primitive unit cell and shortest reciprocal lattice vectors in solid-state physics requires lattice basis reduction algorithms directly descended from the Euclidean algorithm. 2. Periodic Boundary Conditions & Minimum Image Convention: Simulating molecular dynamics on toroidal topologies requires fast integer lattice projections. 3. High-Performance Cluster Arithmetic: Bitwise integer reductions (such as Stein’s binary GCD) are critical in cryptography, pseudo-random number generation (PRNGs for Monte Carlo simulations), and arbitrary-precision arithmetic.

2. Divisibility Axioms and the Subtractive Difference Lemma

2.1 The Divisibility Invariant

Let \(a, b \in \mathbb{Z}^+\) with \(a > b\). The greatest common divisor \(\gcd(a, b)\) is invariant under subtraction:

NoteFundamental Subtractive Lemma

\[\gcd(a, b) = \gcd(b, a - b)\]

Proof: If \(d \mid a\) and \(d \mid b\), then \(a = k_1 d\) and \(b = k_2 d\). The difference is \(a - b = (k_1 - k_2)d\), meaning \(d \mid (a - b)\). Conversely, if \(c \mid b\) and \(c \mid (a - b)\), then \(a = (a - b) + b = c(m_1 + m_2)\), so \(c \mid a\). Thus the common divisors of \((a, b)\) are identical to the common divisors of \((b, a - b)\), and their maxima coincide. \(\blacksquare\)

3. The Division Remainder Algorithm and Lamé’s Bound

Rather than repeated subtraction (\(O(\\max(a, b))\) complexity), the division algorithm subtracts all multiples of \(b\) at once: \[a = q \cdot b + r, \quad 0 \leq r < b\] Yielding the recurrence: \[\gcd(a, b) = \gcd(b, a \bmod b)\]

3.1 Lamé’s Theorem in Computational Physics

The worst-case input for the Euclidean algorithm occurs when the quotients are all \(1\), producing consecutive Fibonacci numbers: \[(r_0, r_1) = (F_{k+1}, F_k)\] By Lamé’s Theorem (1844), the number of division steps \(k\) is bounded logarithmically: \[k \leq 5 \log_{10}(\\min(a, b))\] This guarantees exponential efficiency \(\\mathcal{O}(n)\) in bit-length, enabling high-speed arithmetic inside physical simulation loops.

4. Hardware Optimization: Stein’s Binary GCD on HPC Architecture

On high-performance computing clusters (such as the UTSC art-1 and art-16 clusters), integer division (idiv) costs \(20\)–\(40\) clock cycles, whereas bit-shifts (>> 1), bitwise tests (& 1), and subtractions execute in a single cycle.

4.1 The Binary Invariance Rules

Stein’s algorithm eliminates division entirely: 1. Both Even: \(\gcd(2u, 2v) = 2 \gcd(u, v)\) 2. One Even, One Odd: \(\gcd(2u, v) = \gcd(u, v)\) if \(v \equiv 1 \pmod 2\) 3. Both Odd: \(\gcd(u, v) = \gcd((u - v)/2, v)\) for \(u \geq v\)

In vector processing (SIMD / AVX-512) and GPU computing (CUDA), this allows branch-free implementations using bitwise intrinsics (__builtin_ctz for count-trailing-zeros).

5. Crystallography: 2D Gauss-Lagrange Lattice Reduction as a Vector Euclidean Algorithm

In condensed matter and computational materials science, an experimental crystal structure is specified by arbitrary non-orthogonal basis vectors \(\\mathbf{v}_1, \\mathbf{v}_2 \in \\mathbb{R}^2\).

To identify the primitive Wigner-Seitz cell and construct the first Brillouin zone, one must find a reduced basis satisfying: \[\|\mathbf{u}\| \leq \|\mathbf{v}\| \quad \text{and} \quad |\mu| = \frac{|\mathbf{u} \cdot \mathbf{v}|}{\|\mathbf{u}\|^2} \leq \frac{1}{2}\]

The Gauss-Lagrange algorithm is the exact 2D vector generalization of Euclid’s algorithm: 1. Ensure \(\|\mathbf{u}\| \leq \|\mathbf{v}\|\). 2. Subtract the nearest integer multiple of \(\mathbf{u}\) from \(\mathbf{v}\): \[q = \left\lfloor \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|^2} + 0.5 \right\rfloor, \quad \mathbf{v} \leftarrow \mathbf{v} - q \mathbf{u}\] 3. If \(\|\mathbf{v}\| < \|\mathbf{u}\|\), swap \(\mathbf{u}\) and \(\mathbf{v}\), and repeat.

This algorithm terminates in \(O(\log(\text{cond}(B)))\) iterations, producing the optimal crystallographic basis for spectral and band-structure computations.

## 5. Crystallography: 2D Gauss-Lagrange Lattice Reduction as a Vector Euclidean Algorithm

In condensed matter and computational materials science, an experimental crystal structure is specified by arbitrary non-orthogonal basis vectors $\\mathbf{v}_1, \\mathbf{v}_2 \in \\mathbb{R}^2$. 

To identify the **primitive Wigner-Seitz cell** and construct the **first Brillouin zone**, one must find a **reduced basis** satisfying:
$$\|\mathbf{u}\| \leq \|\mathbf{v}\| \quad \text{and} \quad |\mu| = \frac{|\mathbf{u} \cdot \mathbf{v}|}{\|\mathbf{u}\|^2} \leq \frac{1}{2}$$

The **Gauss-Lagrange algorithm** is the exact 2D vector generalization of Euclid's algorithm:
1. Ensure $\|\mathbf{u}\| \leq \|\mathbf{v}\|$.
2. Subtract the nearest integer multiple of $\mathbf{u}$ from $\mathbf{v}$:
   $$q = \left\lfloor \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|^2} + 0.5 \right\rfloor, \quad \mathbf{v} \leftarrow \mathbf{v} - q \mathbf{u}$$
3. If $\|\mathbf{v}\| < \|\mathbf{u}\|$, swap $\mathbf{u}$ and $\mathbf{v}$, and repeat.

This algorithm terminates in $O(\log(\text{cond}(B)))$ iterations, producing the optimal crystallographic basis for spectral and band-structure computations.
