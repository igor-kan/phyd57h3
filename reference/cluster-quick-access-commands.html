1. Shorthand Commands via ~/.ssh/config

When using your local configuration in ~/.ssh/config, the connection aliases route traffic through the appropriate gateway and host key algorithms automatically:

# Gateway GPU node (Rocky Linux / Dual RTX 3090 + RTX 3080 Ti & Intel oneAPI)
ssh phi-10

# Legacy master node (CentOS 6.6, gfortran, DISLIN graphics — jumps through phi-10)
ssh art-1

# Classroom exercise node (CentOS 6.6 — jumps through phi-10)
ssh art-2

# 16-Core modern compute node (Rocky Linux 9.6, internal cluster backplane via art-1)
ssh art-16

2. Direct CLI Commands (Bypassing SSH Config)

If connecting from a fresh machine, lab workstation, or portable terminal without ~/.ssh/config:

phi-10 (Public Gateway / GPU Node)

ssh -X phyd57@phi-10.utsc.utoronto.ca

art-1 (Legacy Master Node — Requires DSA Host Key)

  • On-campus / Direct UTSC Network:

    ssh -X -o HostKeyAlgorithms=+ssh-dss phyd57@art-1.utsc.utoronto.ca

  • Off-campus (Proxy Jump through phi-10):

    ssh -J phyd57@phi-10.utsc.utoronto.ca -X -o HostKeyAlgorithms=+ssh-rsa,ssh-dss phyd57@art-1.utsc.utoronto.ca

art-2 (Exercise Node — Proxy Jump through phi-10)

ssh -J phyd57@phi-10.utsc.utoronto.ca -X -o HostKeyAlgorithms=+ssh-rsa,ssh-dss phyd57@art-2.utsc.utoronto.ca

art-16 (16-Core Modern CPU Node — Dual Jump via phi-10 and art-1)

ssh -J phyd57@phi-10.utsc.utoronto.ca,phyd57@art-1.utsc.utoronto.ca -X phyd57@192.168.100.160

## 2. Direct CLI Commands (Bypassing SSH Config)

If connecting from a fresh machine, lab workstation, or portable terminal without `~/.ssh/config`:

### `phi-10` (Public Gateway / GPU Node)
```bash
ssh -X phyd57@phi-10.utsc.utoronto.ca
```

### `art-1` (Legacy Master Node — Requires DSA Host Key)
- **On-campus / Direct UTSC Network:**
  ```bash
  ssh -X -o HostKeyAlgorithms=+ssh-dss phyd57@art-1.utsc.utoronto.ca
  ```
- **Off-campus (Proxy Jump through `phi-10`):**
  ```bash
  ssh -J phyd57@phi-10.utsc.utoronto.ca -X -o HostKeyAlgorithms=+ssh-rsa,ssh-dss phyd57@art-1.utsc.utoronto.ca
  ```

### `art-2` (Exercise Node — Proxy Jump through `phi-10`)
```bash
ssh -J phyd57@phi-10.utsc.utoronto.ca -X -o HostKeyAlgorithms=+ssh-rsa,ssh-dss phyd57@art-2.utsc.utoronto.ca
```

### `art-16` (16-Core Modern CPU Node — Dual Jump via `phi-10` and `art-1`)
```bash
ssh -J phyd57@phi-10.utsc.utoronto.ca,phyd57@art-1.utsc.utoronto.ca -X phyd57@192.168.100.160
```
